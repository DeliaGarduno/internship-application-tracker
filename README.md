# Internship Application Tracker

A web application to organize and track software development internship applications. 

## About the Project. 

I am a Web Development undergraduate student building this project to strengthen my programming skills and prepare for software development internships. 

The application allows users to add and delete internship applications. 

## Technologies Used 

-HTML 
-JavaScript

## Current Features 

-Add internship applications 
-delete internship applications 
-form validation 
-DOM manipulation 
-event handling

##Future Improvements 

-Improve the user interface with CSS 
-save applications using localstorage 
-add application status tracking
